# Enterprise AI Operations Copilot

A progressive portfolio project built with Java 17, Spring Boot 3,
Spring AI and OpenAI.

## Delivery roadmap

- Part 1: Chat, structured output and selective tool calling
- Part 2: RAG, bounded workflows and multimodal extraction
- Part 3: Security, guardrails, approvals, caching and observability

Each part is developed, tested and merged progressively.
